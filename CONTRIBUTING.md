# Contributing

Thanks for taking the time! This is a small personal site, so contributions are mostly bug fixes, typos and translation improvements.

1. Open an issue first for anything bigger than a small fix.
2. Fork the repo and create a branch from `master`.
3. Run `npm install`, then `npm run dev` to work locally.
4. If you change text, update both `messages/en.json` and `messages/fr.json`.
5. Make sure `npm run lint` and `npm run build` pass.
6. Open a pull request describing what you changed and why.
